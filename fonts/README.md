# Polices embarquées

`DejaVuSans.ttf` et `DejaVuSans-Bold.ttf` — projet DejaVu (<https://dejavu-fonts.github.io>),
licence libre Bitstream Vera + ajouts dans le domaine public (redistribution autorisée).

Embarquées pour que le rendu en mode dev (Windows/macOS) utilise exactement les mêmes
métriques que le Pi (paquet `fonts-dejavu-core`) : un layout validé sur le poste de
travail est garanti identique sur l'écran.
